# Installer l'application

L'app doit d'abord être en ligne en **HTTPS** (GitHub Pages, voir README). Elle ne s'installe pas depuis un fichier local.

## iPhone (Safari)

1. Ouvre l'adresse de l'app dans **Safari** (pas Chrome : sur iPhone, seul Safari permet « Sur l'écran d'accueil » de façon fiable).
2. Touche le bouton **Partager** (carré avec une flèche).
3. Choisis **Sur l'écran d'accueil**, puis **Ajouter**.
4. Lance l'app depuis l'icône « Performance » : elle s'ouvre en plein écran, sans barre Safari.

Important sur iPhone :
- L'app installée et Safari ont des **stockages séparés**. Importe ton historique **depuis l'app installée**, pas depuis l'onglet Safari.
- Ouvre l'app une première fois avec du réseau : elle se met en cache pour fonctionner ensuite hors ligne.
- Dans Profil › Stockage, touche « Demander un stockage persistant ». iOS peut effacer les données d'un site non utilisé pendant plusieurs semaines : **exporte une sauvegarde régulièrement** (Profil › Sauvegarde).
- Caméra (scanner) et GPS : iOS demande l'autorisation la première fois. En cas de refus : Réglages › Safari › Appareil photo / Position.

## Android (Chrome)

1. Ouvre l'adresse dans **Chrome**.
2. Menu ⋮ › **Installer l'application** (ou « Ajouter à l'écran d'accueil »).
3. Lance l'app depuis l'icône.

## Mettre à jour

Quand une nouvelle version est publiée, un bandeau « Nouvelle version disponible » apparaît. Touche-le : l'app se recharge, **tes données restent intactes**.
